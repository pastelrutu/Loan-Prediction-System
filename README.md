# Loan Prediction System Using Multiple Machine Learning Classification Algorithms

## Project Overview
This project predicts whether a loan application will be approved or rejected using multiple Machine Learning classification algorithms. It compares the performance of different models and automatically selects the best-performing model based on evaluation metrics.

## Features
- Data preprocessing
- Missing value handling
- Label Encoding
- Multiple classification algorithms
- Automatic best model selection
- User input-based loan prediction
- Model performance comparison

## Machine Learning Algorithms Used
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- Gaussian Naive Bayes
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Technologies Used
- Python
- Pandas
- Scikit-learn

## Dataset
Loan Prediction Problem Dataset from Kaggle 
link: https://www.kaggle.com/datasets/altruistdelhite04/loan-prediction-problem-dataset

## How to Run
1. Clone this repository.
2. Install the required Python libraries.
3. Install the dataset from kaggle.com using above link
4. Run the Python script.
5. Enter the applicant details when prompted.
6. View the predicted loan status.

## Project Outcome
The system compares multiple classification algorithms, selects the best-performing model automatically, and predicts whether a loan application should be approved or rejected based on the user's input.
